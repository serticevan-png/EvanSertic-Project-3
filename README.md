# EvanSertic-Project-3
Repository for Project 3

Purpose:
The purpose of this project was to perform a sentiment analysis on reviews by using an API. We needed to find a review, ask our self a question about the selected topic, while using at least 200 reviews, cleaning through the reviews, and finally performing a sentiment analysis on those reviews while answering the question I had asked myself.

Contents:
The attached file contains my procedures and analysis of the review I chose to analyze. It contains my initial question that I had hoped to answer, as well as my conclusion, and the visualizations I had made with my data. Whilst showcasing all the steps I took to get there.
